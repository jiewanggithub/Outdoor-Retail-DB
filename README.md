# Outdoor Retail DB
My PostgreSQL database resides on the Columbia class server under the account lp3159 (database: proj1part2), which is the same one used in Part 2. The live web application is hosted on my course virtual machine and accessible at http://34.148.205.35:8111/. The project fully implements the design proposed in Part 1: a web interface that allows users to browse and manage customers, accounts, stores, items, inventory, and orders, with all operations backed by SQL queries executed directly through Flask using SQLAlchemy connections (no ORM). Additional features include a searchable item catalog that filters by name, type, and price range, a customer creation form that automatically links a new account, and a modern Pico.css-based interface with a pure-CSS rolling image carousel. Two of the most interesting pages are the Item Search page, which dynamically builds parameterized SQL queries from user inputs to retrieve filtered items, and the New Customer page, which demonstrates transactional logic by inserting into both customers and accounts tables within one operation. Overall, the application fulfills the initial proposal, with improved styling and interactivity beyond the original scope.
